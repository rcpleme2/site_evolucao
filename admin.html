Publicar Alterações

As alterações feitas nesta tela ficam só neste navegador até serem publicadas. Publicar grava o arquivo data/dados.json diretamente no repositório do GitHub, para que todos os computadores passem a ver os novos cadastros assim que o GitHub Pages reconstruir o site (leva cerca de 1 minuto).

O token fica só na memória desta aba (sessionStorage) enquanto ela estiver aberta — nunca é salvo em arquivo, nem enviado para qualquer lugar além da API do GitHub.
